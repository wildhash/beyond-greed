## Why ShareAlike?

We use ShareAlike (copyleft) licensing to prevent capture:
- Corporations can't close-source this framework
- Improvements must be shared back to the commons
- The framework remains a public good forever
- No one can extract value by restricting access

This is not anti-commercial—you can build businesses using Beyond Greed. But you must keep the framework itself open and free.
